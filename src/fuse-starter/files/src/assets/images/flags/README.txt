Language flags for the language switcher, loaded as assets/images/flags/<CODE>.svg.

The files come from Flagpack (flagpack-core, size "m"), MIT licensed; see THIRD-PARTY-NOTICES.md.
To add a language, copy its flag from the flagpack-core package into this folder, named by the
two-letter country code (for example DE.svg), and add the language to the Transloco config.
